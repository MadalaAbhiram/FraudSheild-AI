M2 — Supervised Learning: Linear & Logistic Models

Logistic Regression and Stochastic Gradient Descent (SGD) Linear Models serve as fast baseline models for binary fraud classification.

Logistic Regression

Maps linear feature combinations through the sigmoid function to output a fraud probability:

P(fraud=1) = σ(w·x + b) = 1 / (1 + e−(w·x+b))

Configured with class_weight='balanced' to adjust decision boundaries for minority fraud samples.

Linear Model (SGD)

Uses Stochastic Gradient Descent optimization with log loss to compute linear classification boundaries in linear time O(n):

L(y, f(x)) = log(1 + e−y·f(x))

Highly efficient for online training and streaming datasets.

M3 — Supervised Learning: Decision Trees & Ensembles

Tree-based ensemble models (Decision Trees, Random Forests, LightGBM/XGBoost) model complex non-linear feature interactions without requiring explicit feature scaling.

Decision Trees

Recursively partitions feature space to maximize Gini impurity reduction at each split node.

Random Forests & Gradient Boosting

Combines multiple bootstrapped decision trees (Bagging) or sequential residual-correcting trees (Gradient Boosting) for maximum F1-Score performance.

M4 — PCA Feature Identification & Unsupervised Learning

Explores latent feature structures, dimensionality reduction, clustering, and anomaly detection without relying on target labels.

Principal Component Analysis (PCA)

Transforms high-dimensional correlated features into orthogonal principal components (PC1, PC2...) by computing eigenvectors of the covariance matrix:

Σ · v = λ · v

In FraudShield AI, perform_pca() retains 95% cumulative explained variance and identifies top feature loading contributions per component.

K-Means Clustering

Partitions transaction vectors into k=2 centroids by minimizing intra-cluster sum-of-squares distance:

J = Σ Σ ||xᵢ - μₖ||²

Evaluates cluster separation using Silhouette Scores and measures alignment with true fraud labels.

DBSCAN Clustering

Density-based spatial clustering that groups dense regions (core points) and marks sparse, isolated transactions as outlier noise (-1).

Isolation Forest (Anomaly Detection)

Isolates anomalies by randomly selecting features and split values. Anomalous, rare transactions require significantly fewer splits to isolate (shorter path lengths in isolation trees).

M5 — 5-Fold Stratified Cross Validation

Ensures rigorous generalization and prevents evaluation variance by partitioning training datasets into 5 stratified folds.

Stratified 5-Fold Evaluation Protocol

Given extreme class imbalance, StratifiedKFold(n_splits=5) ensures that every fold maintains the exact percentage of positive fraud cases.
